### 1. The Layout-Driven Slider Engine

This logic measures the physical positions of each tab item dynamically. It ensures that when a tab expands with text, the sliding indicator knows exactly how wide to grow and where to slide.

```tsx
const syncIndicator = useCallback((x: number, width: number, immediate = false) => {
  if (width <= 0) return;
  if (immediate) {
    indicatorX.value = x;
    indicatorW.value = width;
  } else {
    indicatorX.value = withTiming(x, { duration: 250, easing: Easing.out(Easing.quad) });
    indicatorW.value = withTiming(width, { duration: 250, easing: Easing.out(Easing.quad) });
  }
}, [indicatorX, indicatorW]);

```
